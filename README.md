# Nabi Desserts — Sitio web

Sitio web de una sola página para **Nabi Desserts**, postres artesanales en Lima.

🔗 **Sitio en vivo:** https://vicomendoza76-sudo.github.io/nabi-desserts-web/

## Sobre este proyecto

- `index.html` es un archivo **único y autocontenido** (HTML + CSS + JS + imágenes en base64). No necesita instalación, build ni dependencias — se publica tal cual con GitHub Pages.
- Secciones: Inicio, Catálogo, Nosotros, Pedidos, Contacto.
- No tiene carrito de compra: cada botón "Pedir" abre WhatsApp con el mensaje ya redactado según el producto.

## Cómo actualizar el sitio

1. Consigue la versión nueva de `index.html` (por ejemplo, generada con ayuda de Claude).
2. En este repositorio, entra al archivo `index.html` → ícono de lápiz (Edit) para pegar el contenido nuevo, o usa **Add file → Upload files** para reemplazarlo directamente.
3. Sube el cambio con un mensaje de commit corto que describa qué se actualizó (ej: "Reemplazo fotos por fotos reales").
4. GitHub Pages publica el cambio automáticamente en 1-2 minutos. No hay pasos adicionales ni que tocar Settings de nuevo.

⚠️ Importante: trata este repositorio como la **fuente de verdad** del sitio. Evita mantener copias sueltas del `index.html` editadas por separado en distintas computadoras — eso genera versiones desincronizadas.
